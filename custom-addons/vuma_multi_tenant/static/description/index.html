Vuma Multi-Tenant Retail

Multi-tenant setup for Trade Rite and Siyaya DC with mixed-basket quote wizard.

Features

  • Dual Company Setup: Complete configuration for Trade Rite and Siyaya DC with separate charts of accounts, warehouses, sequences, pricelists, payment terms, journals, and fiscal positions.
  • Cross-Company Product Search: Search and select products from both companies in a single interface.
  • Mixed-Basket Quote Wizard: Build a single basket with products from both companies, then automatically split into two separate quotations (one per company).
  • No Profile Switching: Create quotes for both companies without changing user company/profile.
  • Company-Specific Configuration: Each quote uses the correct company's pricelist, warehouse, journal, payment terms, and fiscal position.

Workflow

  1. Open Mixed Basket Quote from the Vuma Multi-Tenant menu
  2. Select the customer
  3. Click Add Products to search across both companies
  4. Products are grouped by company (Trade Rite / Siyaya DC)
  5. Add desired quantities to the basket
  6. Review the combined basket with per-company totals
  7. Click Create Quotes to generate two separate sale orders
  8. Each quote is created in its respective company context with correct settings

Security

Access controlled via standard Odoo groups:

  • Mixed Basket User: Can create mixed-basket quotes (implies Sales User)
  • Mixed Basket Manager: Full access including configuration (implies Sales Manager)
